An Image swatch option lets customers choose from **visual samples** — fabric textures, wood grains, material finishes, or style thumbnails — instead of plain text or a flat color chip. If you searched for a **Shopify image swatch option**, this guide explains how it differs from a color dropdown and how to set one up in a few minutes with [Optionify](https://apps.shopify.com/optionify), a free product options app.

## How do I add an image swatch option in Shopify?

Shopify's native variants can only show text or basic color swatches, so they can't display a real material photo per choice. With Optionify, create an option set, add an **Image swatch** option, add each value with its own thumbnail image, assign the set to your products, and enable the theme app embed. Customers then select from visual samples on the product page.

## How is an image swatch different from a color dropdown?

Both are visual pickers, but they solve different problems:

- **[Color dropdown](/articles/color-options)** — shows solid color chips or named colors. Perfect when the choice is a plain, uniform color like "Navy" or "Forest Green."
- **Image swatch** — shows an actual picture for each choice. Use it when the choice has **pattern, texture, or material** a flat color can't convey: linen vs. velvet, oak vs. walnut, matte vs. glossy, or a printed pattern.

If a customer needs to *see the surface* to decide, use an image swatch. If a single solid color says it all, a color dropdown is simpler. And if you don't need a visual at all, a [dropdown menu](/articles/dropdown-options) of text choices may be enough.

## How to set up image swatches in Optionify

1. Click **Create option set** and name the set (e.g. "Upholstery fabric").
2. Add an option and choose the **Image swatch** type.
3. Enter the option label, such as "Choose your fabric" or "Select a finish."
4. Add each choice as a **value** — "Linen," "Velvet," "Boucle" — and upload a thumbnail image for each one.
5. Give any premium choice an add-on price (details below).
6. Decide whether the option is **required** so customers must pick a material before adding to cart.
7. Assign the set with the right [assignment method](/articles/understanding-assign-types) — All Products, Tagged Products, Collections, or Individual Products.
8. Set the set to **Active** and save with Shopify's save bar.

Swatches only appear on the storefront once the **theme app embed** is enabled in your theme editor, so switch it on before you preview.

## Can each image swatch add to the price?

Yes. Every image swatch value can carry an **add-on price** in one of two modes:

- **Fixed** — a set amount, e.g. "Velvet (+$25.00)."
- **Percent** — a percentage of the product price, e.g. "Premium leather (+20%)."

This is ideal for material upgrades where premium options cost more than the standard choice. The add-on charge carries to checkout through a hidden companion product, so it works with **Buy it Now** and **Shop Pay** too. See [pricing variants](/articles/pricing-variants) for how the total reaches the order.

## What image size should I use for swatches?

Use **small, square, evenly sized** images so the swatches align cleanly in a row. Tightly cropped close-ups of the texture or material read far better than full product shots, because the customer is judging the surface, not the whole item. Keep the crop and lighting consistent across every swatch in the option so the set looks deliberate rather than mismatched.

## Real use cases for image swatches

**Furniture and upholstery.** A sofa product offers linen, velvet, and boucle fabric swatches, with premium fabrics priced higher than the standard weave.

**Made-to-order apparel.** A [made-to-measure](/articles/made-to-measure-shopify) shirt shows real fabric close-ups — oxford, poplin, twill — so customers pick the weave they want.

**Materials and finishes.** A cabinetry or countertop store shows oak, walnut, and marble finishes as image swatches, each priced by material.

**Style and design thumbnails.** A custom sign, invitation, or print shop shows style thumbnails so shoppers pick a look at a glance.

Because each selection is saved as a line item property on the order, your fulfillment team sees the exact fabric or finish the customer chose — no ambiguity between similar-sounding names. Since swatches aren't variants, they never create SKUs or count against Shopify's [3-options-per-product limit](/articles/shopify-variant-limit), so you can offer a wide material range on a single product.
