Deciding where your custom fields appear is half the work of setting up product options. This guide explains how to **assign product options to products in Shopify** using [Optionify](https://apps.shopify.com/optionify), a free product options app, and which of its four assignment methods fits each situation. Every option set you build in the **Option Set Editor** carries an assignment that controls exactly which products show it.

![The assignment section of the Optionify Option Set Editor showing the four assignment methods](/images/understanding-assign-types/assignment-methods-overview.png)
*Choose an assignment method for each option set in the Option Set Editor*

## How do I assign product options to products in Shopify?

Open your option set in the Option Set Editor and pick an assignment method: **All Products**, **Tagged Products**, **Collections**, or **Individual Products**. Set the option set to **Active** and save with Shopify's save bar. Options render on the storefront once the theme app embed is enabled in your theme editor.

## The four assignment methods

Optionify gives every option set one of four ways to reach your products. Each trades scope for precision differently, so the right choice depends on whether you're applying a store-wide field or a one-off customization.

### 1. All Products

**What it does:** applies the option set to every product in your store, and automatically includes any new products you add later.

**When to use it:** store-wide fields that make sense everywhere — a "gift message" textarea, a "special delivery instructions" note, or an optional [gift wrapping switch](/articles/gift-wrapping-shopify). Because it's global, you set it once and never revisit it as your catalog grows.

The trade-off is that you can't exclude individual products, so reserve All Products for genuinely universal fields. Anything category- or attribute-specific belongs in one of the targeted methods below.

### 2. Tagged Products

**What it does:** shows the option set only on products carrying one of the tags you specify. This is the most flexible method and usually the one merchants reach for most.

**When to use it:** characteristics that cut across your categories. A tag like `engravable` can span rings, watches, and leather goods at once; `custom-size` can span shirts and jackets. You add or remove products from the option set simply by editing their tags in the Shopify admin — no need to touch the option set again.

![Entering tags in the Tagged Products assignment field in the Option Set Editor](/images/understanding-assign-types/tagged-products-interface.png)
*Target products by tag, then tag items in your Shopify admin to activate the set*

To use it, choose **Tagged Products**, enter one or more tags, and save. Then tag the matching products in **Shopify admin → Products → Tags**. A product that carries any one of the listed tags will show the option set. Keep tag names lowercase, hyphenated, and consistent (`gift-wrap`, `personalizable`, `custom-text`) so they stay easy to manage.

### 3. Collections

**What it does:** applies the option set to every product inside the Shopify collections you select, including products added to those collections later.

**When to use it:** when your options line up with categories you already maintain. A "Rings" collection can carry a ring-size [dropdown](/articles/dropdown-options); a "Wedding" collection can carry a [delivery date picker](/articles/datepicker-options). Because it rides on your existing merchandising, there's no extra tagging to manage — membership in the collection is the trigger.

Collections are less granular than tags: a product has to actually belong to the collection, and you can't target an attribute that spans several collections without adding the set to each one.

### 4. Individual Products

**What it does:** shows the option set only on the specific products you hand-pick.

**When to use it:** precise, low-volume targeting — a bespoke product, a limited edition, or a controlled test before you roll an option out more widely. You search for and select each product directly, giving you complete control and zero risk of the option appearing where it shouldn't.

The cost is maintenance: you manage each product manually, and you have to remember to add new products yourself. It doesn't scale, so it's best for a handful of items rather than a category.

## Which assignment method should I use?

Use **All Products** for universal fields, **Tagged Products** for characteristics that cross categories, **Collections** when options match your existing store categories, and **Individual Products** for a small, hand-picked set. Most stores combine several — a global gift message plus tag-based engraving, for example.

| Method | Best for | Scales as you grow | Precision |
|--------|----------|-------------------|-----------|
| **All Products** | Universal fields | Automatic | Low |
| **Tagged Products** | Attributes across categories | High | High |
| **Collections** | Category-based options | Automatic | Medium |
| **Individual Products** | Specific or test items | Manual | Highest |

## Tags vs. collections: what's the real difference?

Tags describe **attributes** and can span any category — `engravable` applies to a ring and a wallet alike, and you control it product by product. Collections describe **categories** and follow your existing merchandising, automatically including new products you add to them. Choose tags for cross-category traits, collections for category-wide rules.

## How to combine methods in a real store

A single store usually mixes methods. For example, a jewelry store might run:

- **Gift message** (All Products) — available on every item
- **Engraving text** with a [character limit](/articles/text-options) (Tagged: `engravable`) — only on pieces that can be engraved
- **Ring size** (Collection: "Rings") — every product in the rings category
- **Bespoke design consultation** (Individual Products) — one premium made-to-order piece

Layering assignments this way keeps each product page showing only the fields that belong on it. Pair this with [conditional logic](/articles/conditional-logic) to hide sub-options until they're relevant, and you avoid cluttered pages entirely.

## Can I change an assignment after saving?

Yes. Open the option set in the Option Set Editor, switch the assignment method or edit its tags, collections, or product list, and save with Shopify's save bar. Changes take effect on the storefront immediately once the set is **Active**. There's no separate publish step — Active status plus a saved change is all it takes.

## FAQ

**How do I assign product options to products in Shopify?**
Open your option set in the Option Set Editor, choose All Products, Tagged Products, Collections, or Individual Products, set the set to Active, and save with the save bar. Options render once the theme app embed is enabled.

**Can one option set apply to multiple products?**
Yes. All Products covers your whole catalog, Tagged Products covers every product with a matching tag, and Collections covers every product in the chosen collections. Individual Products lets you hand-pick items instead.

**What is the difference between tags and collections for assignment?**
Tags target attributes that cross categories and update as you tag products. Collections follow your existing store categories and include new products automatically. Use tags for characteristics, collections for categories.

**Can I change how an option set is assigned later?**
Yes. Reopen the set in the Option Set Editor, change the method or its targets, and save. The update applies on the storefront as soon as it's saved and the set is Active.

**Why isn't my option showing on a product?**
Confirm the set is Active, that the product matches the assignment (right tag or collection), and that the Optionify theme app embed is enabled in your theme editor. Options only appear when the embed is on.
