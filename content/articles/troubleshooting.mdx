If your **Optionify options are not showing on the product page**, the cause is almost always one of four things — and each has a quick fix. This guide walks through them in the order to check, then covers add-on prices that don't appear and where option data shows up in orders. Work top to bottom and you'll resolve nearly every case in a couple of minutes.

## Why are my Optionify options not showing on the product page?

The four usual causes are: the option set is still in **Draft** instead of Active, the **theme app embed** isn't enabled in your theme editor, the set **isn't assigned** to that product, or a change was **never committed** with Shopify's save bar. Fixing these four resolves almost every case. Check them in that order.

![A Shopify product page with Optionify options rendered below the price](/images/troubleshooting/options-on-product-page.png)
*When all four conditions are met, options render on the live product page*

## Fix 1: Set the option set to Active

Optionify sets have two statuses: **Active** and **Draft**. A Draft set never appears on the storefront — there is no separate "Publish" button. Open the set in the Option Set Editor, change the status to **Active**, and commit the change with the save bar (see Fix 4). If you just created the set and it's not showing, this is the most common reason.

## Fix 2: Enable the theme app embed

Options render on the storefront through Optionify's **theme app embed**. If it's switched off, nothing appears no matter how the set is configured. To enable it:

1. In Shopify admin, go to **Online Store → Themes**.
2. Click **Customize** on your live theme.
3. Open **Theme settings** (the gear icon) and the **App embeds** tab.
4. Turn on the **Optionify** embed.
5. Click **Save**.

![The Shopify theme editor App embeds panel with the Optionify embed toggled on](/images/troubleshooting/theme-app-embed-toggle.png)
*Enable the Optionify theme app embed in the theme editor's App embeds tab*

Do this on the theme you're actually publishing. If you've recently switched themes, the embed must be enabled on the new one.

## Fix 3: Assign the set to the product

An Active set only shows on products it's **assigned** to. Optionify offers four [assignment methods](/articles/understanding-assign-types):

- **All Products** — appears on every product.
- **Tagged Products** — appears on products carrying a specific tag.
- **Collections** — appears on products in chosen collections.
- **Individual Products** — appears only on products you pick.

If you used Tagged Products, confirm the product actually has that tag. If you used Collections, confirm the product is in the collection. A mismatch here is a frequent reason an otherwise-correct set doesn't appear on one specific product.

## Fix 4: Commit changes with the save bar

Optionify saves through **Shopify's save bar** — the bar that slides in at the top of the screen when you make an edit. If you change a status, add a value, or set a price and then navigate away without clicking **Save** in that bar, the change is never committed and won't go live. After any edit, look for the save bar and confirm you've saved. This step catches the "I definitely set it to Active but it's still not showing" cases.

## Why isn't the add-on price showing or being charged?

Work through these checks:

- **The value has a price.** Open the option value and confirm an **add-on price** is set as **Fixed** or **Percent**. A value with no price simply adds nothing.
- **The set is Active and saved.** A priced option in a Draft or uncommitted set won't charge anything (Fixes 1 and 4).
- **The embed is on.** Prices render with the option, so the embed must be enabled (Fix 2).
- **Test on the live page.** Select the option on the storefront and watch the total. Add-on charges reach checkout through a **hidden companion product**, so they also apply with Buy it Now and Shop Pay. See [product option pricing](/articles/pricing-variants) for how the total is built.

If the option shows but the price doesn't, it's almost always a missing price on the value or an uncommitted save.

## Where does option data appear in orders?

Every selection a customer makes is saved as a **line item property** on the Shopify order. Open the order in Shopify admin to see each chosen option and any add-on charge applied. Your fulfillment team reads the customer's inputs — engraving text, uploaded files, chosen extras — directly from the order, with no separate spreadsheet.

If option data is **missing** from an order, the most likely explanation is that the customer placed the order before the set was Active or assigned, or before the theme app embed was enabled. Data is only captured for options that were actually live when the customer checked out.

## Still not showing? A quick checklist

Run through this before reaching out:

1. Set status is **Active** and saved via the save bar.
2. **Theme app embed** is enabled on the published theme.
3. The set is **assigned** to the product (right tag / collection / individual selection).
4. You're viewing the **correct product** and the **published theme**.
5. Use the editor's **Preview** action — it opens a product the set is assigned to on the storefront, which confirms the set is wired up correctly.

## Getting help

If you've worked through all four fixes and options still don't appear, contact support through the Optionify app in your Shopify admin. Include the product URL, the option set name, and which of the checks above you've already confirmed — that gets you a faster answer.

## FAQ

**Why are my Optionify options not showing on the product page?**
Usually one of four things: the set is in Draft, the theme app embed is off, the set isn't assigned to that product, or a change wasn't committed with the save bar. Check them in that order.

**How do I enable the Optionify theme app embed?**
Go to Online Store → Themes → Customize, open Theme settings → App embeds, turn on the Optionify embed, and click Save. Options render through this embed.

**Why is my option set active but still not showing?**
An active set only appears on products it's assigned to. Check the assignment method and confirm the product qualifies, and make sure your edit was committed with the save bar.

**Why isn't the add-on price showing or being charged?**
Confirm the value has a Fixed or Percent price, the set is Active and saved, and the embed is enabled. Charges reach checkout through a hidden companion product.

**Where does option data appear in Shopify orders?**
Every selection is saved as a line item property on the order, visible in Shopify admin. Missing data usually means the set wasn't live when the customer checked out.
